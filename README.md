# Python Assignment 3 – Loops & Functions

A Python programming assignment covering **While Loops, For Loops, Control Statements, and Functions**.

## 📌 Assignment Overview

This assignment focuses on applying fundamental Python concepts through three practical programs:

### 1. 🎯 Number Guessing Game
A simple guessing game using a `while` loop and control statements.

**Concepts Covered:**
- `while` loop
- `if`, `elif`, `else`
- `break`
- `continue`
- `while-else`
- `random.randint()`
- User input and validation

The program generates a random number between **1 and 10** and gives the user a maximum of **3 attempts** to guess it.

### 2. ✖️ Multiplication Table Generator
Generates a multiplication table from **1 to 10** for a number entered by the user.

**Concepts Covered:**
- `for` loop
- `range()`
- User input
- Arithmetic operations
- Formatted output

### 3. 🧮 BMI Calculator
Calculates the **Body Mass Index (BMI)** using a user-defined function.

**Concepts Covered:**
- Functions
- Function parameters
- `return` statement
- User input
- Arithmetic operations

**Formula:**

`BMI = weight / (height²)`

## 🛠️ Technologies Used

- Python 3
- Jupyter Notebook

## 📂 Programs Included

| Program | Main Concepts |
|---|---|
| Number Guessing Game | While Loop, `break`, `continue`, `else` |
| Multiplication Table | For Loop, `range()` |
| BMI Calculator | Functions, Parameters, `return` |

## 🎯 Learning Outcome

Through this assignment, I practiced using **loops, control statements, functions, parameters, return values, user input, and basic problem-solving techniques in Python**.
